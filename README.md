# 重量波动折线图分析（离线版）

一个纯前端的 Excel 重量数据分析工具，导入后生成时间—重量折线图，支持波动阈值过滤、局部放大、事件统计与数据导出。**所有计算都在浏览器本地完成，数据不出本机。**

## 功能特性

- **Excel / CSV 导入**：支持 `.xlsx` / `.xls` / `.csv`，多工作表可切换，自动识别首行是否为表头。
- **拖拽导入**：把文件拖到页面任意位置即可导入，松手自动读取，界面同步出现拖拽提示。
- **导入文件名**：导入后「导入数据」下方显示 `当前导入：<文件名>`，换文件自动替换。
- **辅助列（双 Y 轴）**：可选第 3 列（速度 / HZ / 其它）作为辅助折线，橙色 50% 透明、挂在右侧 Y 轴，重量线仍在左轴且置于上层不被遮挡。
- **坐标轴手动 min/max**：左右轴各可手动设最小/最大值，默认值 = 无余量（数据本身的 min/max）；旁有「默认」按钮一键恢复。手动最小 > 数据最小、或手动最大 < 数据最大 时该输入框标红。缩放视图时手动值自动切回默认。
- **坐标轴默认值圆整**：重量轴默认 max = 数据 max + 其 5% 预留后向上圆整到 1/5/10/50/100… 台阶；默认 min 向下圆整同台阶。辅助轴同法。
- **图例当前值**：图例行实时显示重量（末点 kg）与辅助（末点）当前值。
- **列手动修正**：时间列、重量列均可用下拉框指定到任意列；带表头时显示「A · 列名」。
- **时间格式兼容**：Excel 时间序列号（如 `45000.5`）、`2026-08-11 08:00:05`、纯 `08:00:05` 等，精确到秒。
- **折线图 + 悬停提示**：鼠标悬停显示「时间 + 当时重量 + 辅助值」。图上不再绘制上料/出料标记符号（判定结果只在统计面板与数据预览表中体现）。
- **波动阈值检测**：界面可调「时间窗口（秒）」+「重量差阈值（kg）」。
  - 窗口内重量波动 ≥ 阈值 → 判定为真实上料/出料；否则视为平稳噪声。
  - 「高亮平稳段」开关：把噪声段用灰色底色标出。
- **局部放大**：滚轮缩放 + 底部滑块 + 工具栏「框选放大」拖框选定时间段。
- **统计面板**：有效点数、上料/出料事件次数、净重量变化、单次最大波动、最大/最小重量。
- **数据预览表**：显示当前数据（默认全部前 1000 行，或当前放大区域前 1000 行），每行标注「上料 / 出料 / 平稳 / 起点」。
- **跟随放大区域**：开关控制统计面板与预览表是否随图表缩放切换为「视图内」数据。
- **导出**：折线图存 PNG（工具栏「保存图片」）。
- **基准线**：点「点选基准」（或图表顶部「基准线」图标），光标变十字后在图上点一下选定基准时间；**基准重量自动取该时间点的重量**，并画一条红色横线（50% 透明）。「设定重量」为独立输入，用于算偏差。开启后悬停 tooltip 多显示一行：**差值 = 悬浮处重量 − 基准线重量（正红负绿）**，以及**偏差比例 = (|差值| − 设定重量) / 设定重量**（百分比 %）。

## 使用方法

### 方式一：双击本地文件
直接双击 `index.html`（或单文件版 `weight-chart.html`）即可使用，无需联网、无需服务器。

### 方式二：静态部署
整个 `weight-chart/` 目录（或仅 `weight-chart.html` 单文件）可直接托管到任意静态服务器 / 对象存储 / CDN。相对路径保持原样即可。

## 操作说明

| 控件 | 说明 |
|------|------|
| 选择 Excel 文件 | 导入数据（也可把文件直接拖到页面上） |
| 工作表 | 多工作表时切换 |
| 首行是表头 | 勾选后第一行作为列名，不计入数据 |
| 时间列 / 重量列 | 指定第几列为时间 / 重量，默认第 1 / 第 2 列 |
| 辅助列 | 可选第 3 列画橙色辅助折线（右轴，50% 透明，重量线在上层）；「无」= 不显示 |
| 时间窗口（秒） | 判定波动的时间范围，如 `10` |
| 重量差阈值（kg） | 窗口内波动超过该值才算有效上/出料，如 `0.01` |
| 高亮平稳段 | 勾选后用灰底标出噪声段 |
| 跟随放大区域 | 勾选后统计面板与预览表随缩放切换为视图内数据 |
| 重量轴（左）/ 辅助轴（右） | 手动设坐标 min/max，默认无余量；「默认」一键恢复；越界标红 |
| 基准线 | 点「点选基准」后在图上点一下选定基准时间（基准重量取该点重量）；「设定重量」用于算偏差比例；红线为基准重量，悬停看差值与偏差 |

| 框选放大（图表顶部工具栏） | 拖框选定时间段放大 |
| 基准线（图表顶部工具栏） | 未设基准时进入点选模式；已设基准时一键显示/隐藏 |

## 算法说明

采用**窗口波动（range-window）**检测：对每个数据点，取 `[t-T, t]` 时间窗内的所有点，计算窗口内最大与最小重量之差（波动幅度）。

- 波动幅度 ≥ 重量差阈值 → 该点为有效事件点，方向由上一次有效值到当前值增减决定（增 = 上料 ▲，减 = 出料 ▼）。
- 否则 → 平稳（噪声）点。
- 连续同向事件点聚合成一段，统计单次波动幅度（`max − min`）。
- 净重量变化 = 末点重量 − 首点重量。

> 提示：数据本身若存在 ±0.01 kg 量化噪声，把「重量差阈值」调到 `0.015~0.02` 可避免把噪声误判为事件。

## 注意事项

- 修改时间窗口、阈值、显示选项时，当前缩放视图会保持不变（不会重置）。
- 导入新文件、切换工作表、改时间列/重量列、切换表头时，视图会重置（数据已变化）。
- 大数据量（数万点）时已启用 ECharts `large` 模式降采样，保证交互流畅。
