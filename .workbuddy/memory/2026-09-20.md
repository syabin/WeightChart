### 改动

## 重量波动折线图分析工具 —— 控件区 UI 重构（分组卡片）

用户反馈顶部控件区「很乱」（截图圈了重量轴/辅助轴/显示选项）。根因：所有 field 平铺在一个 flex-wrap 容器里，无分组层次、label 行高参差、组间仅靠细线分隔，且「重量轴（左）」被挤到第一行最右、「辅助轴（右）」掉到第二行最左。

### 改动（仅 `index.html`，未动 app.js）
- CSS：`.controls` 改 `align-items:flex-start`；新增 `.group`（浅底 `#fafbfe` + 1px 边框 + 圆角 10px + padding）、`.group .gtitle`（蓝色小标题 + 左侧 3px 竖条 `::before`）、`.gbody`（组内 flex，`align-items:flex-start`）、`.axis-row`、再次删除已无用的 `.sep`。
- 结构：把原平铺控件拆成 5 个分组卡片：
  1. **数据源**：导入数据按钮 / 工作表 / 首行表头
  2. **列映射**：时间列 / 重量列 / 辅助列
  3. **坐标轴范围**：重量轴（左）+ 辅助轴（右）——两个轴终于相邻同组
  4. **基准线**：基准时间 / 基准重量 / 设为基准 / 清除 + hint
  5. **分析设置**：时间窗口 / 重量差阈值 / 显示选项（两个 chk 竖排）
- 各组加 `min-width`（212/196/238/330/300）保证组内不换行；`.field label` 加 `white-space:nowrap`；`.axis-input.baseline-time` 加宽到 136px。
- 底部总 hint 精简为一行。

### 设计要点
- 分组 = 「关联控件同组」，解决原「重量轴与辅助轴被拆散」的核心混乱。
- 全部 id 原样保留（仅改结构与 CSS），app.js 零改动、零风险。
- 组内 `align-items:flex-start` + label 统一单行 → 各控件顶部/底部自然对齐，不再参差。

### 验证
- 脚本比对：app.js 引用的 33 个 id 在 index.html 全部存在、无缺失、无重复 id。
- 待用户双击 `index.html` 看效果。

## 重量波动折线图分析工具 —— tooltip 基准区换行 + 修「统计面板显示不全」

用户反馈两点：① tooltip 里「差值」要和基准挤在一行了，要换新行；② 右侧统计面板显示不全（被压扁，只剩标题）。

### 改动
- `app.js`（tooltip formatter）
  - 基准信息区由「一行拼接（基准 · 差值 · 偏差）」改为**三行独立**：
    - `基准 135.910 kg（2026-09-19 11:17:45）`（时间用灰字 #9aa3b2 弱化）
    - `差值 −10.950 kg`（**正红负绿** #e0533d / #2f9e6f）
    - `偏差 −75.67%`（仅当 `setWeight` 有效时显示；`(|差值| − 设定重量)/设定重量`）
  - 各行 `margin-top:3px`，区首保持虚线分隔。
- `index.html`（CSS）
  - **统计面板被压扁的根因**：`.aside .card{min-height:0}` 未设 `flex-shrink:0`，作为 flex 子项在高度不足时被压缩到只剩标题，且无 overflow → 内容直接不可见。
  - 修复：`.aside .card{flex:0 0 auto}`（统计卡按内容高度、**绝不收缩**）；`.aside .card.grow{flex:1 1 auto; min-height:170px}`（预览卡吸收剩余空间）；`.aside` 加 `overflow-y:auto; overflow-x:hidden; padding-right:2px`（整体不够高时侧栏自身滚动，不再裁内容）。
  - 统计项压紧：`.stat` padding 7px 9px → 6px 8px；`.stat .v` 字号 15px → 14.5px；`.k/.v` 加 `nowrap + ellipsis + min-width:0` 防长值撑破；`.stats` gap 8 → 7。

- `_check.js`：app.js 语法 OK；引用 32 个 id 全部存在；HTML 无重复 id；工具断言「tooltip 差值独立成行=是、统计卡 flex:0 0 auto=是、侧栏 overflow-y:auto=是」。
